Mods for the Classic Minis

A hakchi2-CE repository for the NES, SNES, Famicom, Super Famicom and Shonen Jump Classic: Options Menu, themes, languages and fixes.

{{SITE_URL}}
  1. Install Options Menu first. Its add-ons (Theme Selector, Japanese Font Pack, Gamepad Remapping Tool…) need it. Pick its compat build if another hmod replaces the system libstdc++, for example RetroArch 1.8.4 Xtreme SC.
  2. Official consoles only. Clones and knock-offs are not supported.
  3. Install what you want from the tabs in hakchi, then sync with your console.
